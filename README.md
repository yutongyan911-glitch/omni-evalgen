# EvalGen 智能评测集生成系统

EvalGen 是一款专为 AI 视频生成设计的智能数据集采样与预览工具。它能够基于多维度标签（难度、类目、时长区间等）进行精准的贪心抽样，并提供直观的数据分布大盘，帮助评估人员快速构建高质量的评测集。

## 🚀 核心特性

- **多维度智能采样**：支持根据难度、类目、应用场景、挑战点、running_params 等进行优先级采样。
- **可视化预览大盘**：集成 Recharts，在生成文件前实时查看各维度的分布比例（饼图/柱状图）。
- **双模导出**：支持一键导出“推理测试模版”或“完整数据集”，且保证同一批次内容一致。
- **极客风交互**：沉浸式暗黑/白天模式切换，全屏毛玻璃 UI 设计。
- **团队协作友好**：采用自适应相对路径设计，克隆即用。

## 📦 快速开始

### 1. 克隆项目
```bash
git clone https://github.com/yutongyan911-glitch/omni-evalgen.git
cd omni-evalgen
```

### 2. 放置原始数据
将你的原始 `.xlsx` 数据文件放入项目根目录下的 `data/` 文件夹内。

### 3. 启动后端服务 (Backend)
```bash
cd backend
# 创建虚拟环境
python3 -m venv .venv
source .venv/bin/activate
# 安装依赖
pip install -r requirements.txt
# 运行服务
uvicorn main:app --reload
```
*后端默认运行在 `http://localhost:8000`*

### 4. 启动前端控制台 (Frontend)
```bash
# 新开一个终端窗口
cd frontend
# 安装依赖
npm install
# 运行开发服务器
npm run dev
```
*在浏览器打开终端输出的链接（通常是 `http://localhost:5173`）即可访问。*

## 📖 使用指南

1. **选择数据源**：在顶栏下拉框选择 `data/` 目录下的 Excel 文件。
2. **配置筛选条件**：
   - 设置总抽取题目数量。
   - 拖拽调整维度优先级。
   - 添加具体的筛选逻辑（支持 `=`、`>=`、`<=` 等操作符）。
3. **预览分布**：点击“预览评测集分布”，查看当前抽样结果的统计图表。
4. **按需下载**：在预览弹窗中选择“下载推理模版”或“下载完整评测集”。
